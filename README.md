# 🌻 向日葵的問號

學校兩塊向日葵花圃同一天種下，東邊卻比西邊高了一個頭。玩家在校園裡問人、摸土、看東西、做實驗，找出原因後向林老師報告。

- 對象：國小三到六年級
- 時間：約 10 分鐘
- 裝置：電腦、平板、手機皆可（瀏覽器開啟即可玩）
- 主題：探究精神——分清楚「觀察」和「猜測」、做「公平測試」

## 玩法

1. **移動與互動**：方向鍵／WASD 或左下方向鈕移動；空白鍵、Enter 或「查看」鈕跟人說話、查看東西。
2. **自己決定要問什麼**：每個角色有幾個可以問的問題，有些問題要先找到特定線索才會出現。
3. **線索分類**：每張線索卡都要分成「👀 看到、量到、親手做的」或「💭 有人猜的」。
4. **實驗桌**：A 盆照平常種，B 盆可以改陽光、水、土、種子。一次只改一個地方，才知道是哪個造成差別。
5. **證據報告**：選一個原因、挑 1～4 張證據交給林老師。猜測卡、少了實驗或關鍵觀察，林老師會退回並給方向，不扣分。
6. **結局**：找到真正原因，或隨時交出「還沒寫完的報告」，再回去繼續查。結尾會統計線索數、分類正確率、問題數和實驗次數。

## 技術

單一 `index.html`，不需安裝、不存檔、不連資料庫。
